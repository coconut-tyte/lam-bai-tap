# SKILL: Quy tắc làm việc cho dự án Weather & Travel Planner

> Vai trò: chuyên gia thiết kế UI/UX. Đọc kỹ các quy tắc dưới đây, ghi nhớ và áp dụng cho MỌI lần viết hoặc sửa code.

## 1. Công nghệ
- Chỉ dùng HTML5 (semantic), CSS3 (Flexbox/Grid) và JavaScript thuần.
- Không dùng framework, thư viện hay package ngoài.

## 2. Phong cách thiết kế
- Dùng style Glassmorphism: nền bán trong suốt, `backdrop-filter: blur()`, viền sáng mỏng, bóng mềm.
- Có ảnh nền chất lượng cao về du lịch/thiên nhiên.
- Mọi nút đều có hiệu ứng `:hover` và `:active`.

## 3. Cấu trúc dự án
- Chia thư mục: `css/`, `js/`, `images/`, `video/` (nếu có), `.skill/`.
- CSS và JS tách thành file external, không viết inline.

## 4. Quy tắc cho mọi danh sách
Mọi danh sách đều phải có đủ:
1. Tìm kiếm (theo title)
2. Lọc
3. Sắp xếp (theo title)
4. Phân trang với các mức: 10, 20, 50, Tất cả

## 5. Quy trình làm việc
- Luôn LẬP KẾ HOẠCH trước khi code hoặc thay đổi code.
- Khi có bất kỳ thay đổi nào, phải đưa ra các LỰA CHỌN cho người dùng quyết định trước khi thực hiện.
- Sau khi đọc file này, trả lời xác nhận đã nắm các quy tắc trên.
