Giới thiệu bản thân

Tôi là một lập trình viên web nhiệt huyết, chuyên xây dựng và phát triển các trang web cũng như ứng dụng web hiện đại, chuẩn SEO và tối ưu trải nghiệm người dùng. Tôi luôn chủ động tìm tòi công nghệ mới và sẵn sàng tham gia giải quyết các bài toán thực tế.

Kỹ năng chính

  • HTML5 (Semantic Web, Cấu trúc chuẩn SEO)
  • CSS3 (Flexbox, Grid, Responsive Design)
  • JavaScript (ES6+, DOM Manipulation)
  • Git & Quản lý mã nguồn (GitHub / GitLab)
  • Tối ưu hóa hiệu năng website
